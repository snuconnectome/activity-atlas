## 유지할 결정과 제한

1. `ACTIVITY_ATLAS_SCOPE`를 모든 수집·분석·join 단계에 동일하게 설정한다. `--all-authors`는 수집 범위만 all로 선택하므로 후속 분석에도 all 환경변수가 필요하다.
2. GitHub 수집은 접근 가능한 세 조직의 최근 갱신된 비아카이브 저장소 기본 브랜치에 한정된다. 연결되지 않은 계정·봇·GitHub 밖 활동은 포함하지 않는다.
3. 저자 동의가 private 저장소 공개 허가는 아니다. 공개 예외나 제외 정책을 자동 승인하지 않는다.
4. 활동·기여자 수·PI commit은 각각 시간·예산·성과, 실제 소유권, 실제 면담·검토를 입증하지 않는다. 학생 순위·점수·무활동 자동 판정을 추가하지 않는다.
5. CI 월요일 일정은 저장된 공개 JSON 검증·재렌더·배포만 한다. 새 GitHub 수집·ML은 로컬에서 수행하며 빌드 시각과 수집 시각을 구분한다.
6. Linux renameat2가 없는 플랫폼의 기존 세대 교체는 실패 처리한다. 전원 장애 영속성은 검증하지 않았다.
7. 공개 과거 Git 히스토리 제거, 실제 외부 공지, 전체 저자 실제 갱신, working-memory 결함 F13은 이번 커밋 범위 밖이다.

## Git와 제외 작업

브랜치 `main`, upstream 및 push 대상 `origin/main`, GitHub `snuconnectome/activity-atlas`. 확인 시 원격과 기반 HEAD가 같고 사전 미푸시 커밋·staged 변경은 없었다.

이번 커밋에는 대시보드 코드·공개 파생본·스키마·테스트·CI·문서·리뷰 증거와 이 인수인계만 포함한다. 원래 미추적 `.serena/`, `scripts/workmem.py`, `docs/working-memory.md`는 제외하고 그대로 보존한다. 비공개 원자료와 로컬 ML 파생물도 커밋하지 않는다.
